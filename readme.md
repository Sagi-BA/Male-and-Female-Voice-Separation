
# מפריד קולות פודקאסט בעברית

אפליקציית Streamlit לפיצול קבצי פודקאסט לקולות נפרדים (גברי ונשי)

## תיאור

אפליקציה זו מאפשרת למשתמשים להעלות קובץ פודקאסט המכיל שני דוברים (גבר ואישה) ולהפריד אותו לשני קבצי שמע נפרדים - אחד עבור הקול הגברי ואחד עבור הקול הנשי. האפליקציה פותחה במיוחד עבור פודקאסטים בשפה העברית, עם ממשק משתמש מלא בעברית ותמיכה בכיוון RTL.

## דרישות מערכת

- Python 3.8 ומעלה
- התקנת ספריות מ-requirements.txt

## התקנה

1. הורידו את הקוד מהמאגר:
```bash
git clone https://github.com/your-username/hebrew-podcast-voice-separator.git
cd hebrew-podcast-voice-separator
```

2. התקינו את הספריות הנדרשות:
```bash
pip install -r requirements.txt
```

3. התקינו והגדירו את pyannote.audio:
   - גשו ל-[Hugging Face](https://huggingface.co/) והירשמו לחשבון
   - אשרו את תנאי השימוש עבור [pyannote/speaker-diarization-3.0](https://huggingface.co/pyannote/speaker-diarization-3.0)
   - צרו טוקן גישה ב-[הגדרות החשבון](https://huggingface.co/settings/tokens)
   - החליפו את `YOUR_HF_TOKEN` בקוד עם הטוקן שלכם

## הפעלת האפליקציה

הריצו את הפקודה הבאה:

```bash
streamlit run app.py
```

האפליקציה תיפתח בדפדפן שלכם בכתובת המקומית http://localhost:8501

## שימוש באפליקציה

1. העלו קובץ אודיו (mp3, wav, או m4a) המכיל פודקאסט עם שני דוברים
2. לחצו על "התחילו בהפרדה" כדי להתחיל בתהליך העיבוד
3. המתינו בזמן שהאפליקציה מבצעת את ההפרדה
4. צפו בתוצאות, האזינו לקבצים המופרדים והורידו אותם למחשב שלכם

## הערות מימוש

- האפליקציה משתמשת ב-pyannote.audio לביצוע דיאריזציה (זיהוי דוברים)
- במימוש מלא, יש להוסיף סיווג מגדרי של הקולות (מי גבר ומי אישה)
- ייתכן שתצטרכו להתאים את המודל עבור השפה העברית לתוצאות טובות יותר
